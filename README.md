# Reflection sessions on digital platforms

Key learnings and reflections from each guest speaker session of my ESSEC digital platforms course.

Live site: https://essec-homework-mu.vercel.app

## Files

- `index.html`: structure of the page
- `style.css`: the look (colours, font, layout)
- `app.js`: the behaviour (sideways scroll, session pages, animations)
- `content.js`: all the text, one block per session
- `vercel.json`: security settings for the live site

Built by vibecoding with Claude, hosted on Vercel.
